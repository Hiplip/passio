# Security policy

passio stores people's passwords, so security reports get priority over everything else.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through GitHub:
**Security** tab → **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it.
Reports are read by the maintainer and answered as soon as possible.

## In scope

- Anything that lets the server, or someone who controls it, read vault contents or
  the master password
- Weaknesses in key derivation, encryption or key handling (`packages/crypto`)
- The extension filling a login on the wrong site, or leaking a secret to a page
- Authentication or authorization bypasses in the web app or API

## Out of scope

- Attacks that need an already unlocked device or malware on it
- Missing rate limits or headers with no demonstrated impact
- Reports generated by automated scanners without a working proof

## Supported versions

Only the latest version on `main` and the hosted app are supported.
