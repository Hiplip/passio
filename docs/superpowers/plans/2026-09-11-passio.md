# passio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a zero-knowledge personal password manager with TOTP support, deployed live on Vercel, where the server never sees a plaintext secret.

**Architecture:** A single Next.js App Router app. All cryptography happens in the browser inside `src/lib/crypto/` (pure functions, no I/O, no framework imports), executed in a Web Worker so Argon2id does not freeze the UI. tRPC is a ciphertext store — it authenticates, enforces row ownership, and moves opaque strings, with no server-side decrypt path anywhere. The master password derives both an auth hash (sent to Better Auth in place of a password) and an AES-GCM key that unwraps a randomly generated vault key held only in memory.

**Tech Stack:** Next.js App Router · TypeScript · tRPC · Drizzle ORM · Neon serverless Postgres · Better Auth · Tailwind + shadcn/ui · Vitest · `hash-wasm` (Argon2id, PBKDF2) · WebCrypto (AES-GCM, HKDF) · `otpauth` (TOTP)

**Spec:** `docs/superpowers/specs/2026-09-11-passio-design.md` — read it before starting. This plan implements it.

## Deviations from the spec

Three changes made while writing this plan. All are recorded in `DECISIONS.md`. The spec has been
updated to match, so spec and plan do not contradict each other.

### D1 — `userVaultKey` is folded into the `user` table (replaces spec §4)

**Why:** Spec §5 gated registration inside a tRPC mutation. But Better Auth mounts
`/api/auth/sign-up/email` as a public HTTP route. A direct POST would bypass tRPC entirely,
creating a user row with **no vault key material** — a permanently un-unlockable account — and
defeating the single-account gate.

**Fix:** `protectedVaultKey`, `recoveryWrappedVaultKey` and `kdfVersion` become Better Auth
`user.additionalFields` with `required: true`. Better Auth writes them in the same insert as the
user. A user without key material becomes unrepresentable, and the two-table transaction is gone.

### D2 — the single-account gate moves to a database hook

**Why:** same reason. An application-layer check only guards the path it sits on.

**Fix:** `databaseHooks.user.create.before` counts existing users and returns `false` to abort.
This holds for every entry point — tRPC, the public Better Auth route, or anything added later.

### D4 — `account.register` is gone

**Why:** with D1, signup goes through Better Auth's `signUp.email` carrying the additional fields.
A separate tRPC mutation would be a second, weaker path to the same place.

**Fix:** the client calls `authClient.signUp.email({ email, password: authHash, name,
protectedVaultKey, recoveryWrappedVaultKey, recoveryVerifier })`. `account.status` remains, but
only to decide what the signup page renders — the authoritative gate is D2's database hook.

### D5 — a recovery **verifier** is stored, and it must be created in Phase 1

**Why:** this one is load-bearing and was missing from the spec entirely. The recovery key cannot
authenticate to the server: the server holds only `recoveryWrappedVaultKey`, which is ciphertext,
so it has no way to distinguish a correct recovery key from a wrong one and cannot authorise the
password change that Phase 6 depends on. Without this, **the recovery key is decorative and Phase 6
is impossible.**

**Fix:** `deriveRecoveryAuthHash(display)` derives a separate value from the recovery key under its
own HKDF info string. It is sent at signup and stored as `user.recoveryVerifier`, hashed server-side
with Better Auth's own password hasher inside the D2 hook — so the database holds a hash, not the
value. Phase 6 verifies against it.

**This is why it lands in Phase 1.** The recovery key is displayed exactly once and can never be
reconstructed, so the verifier must be created at the same moment. A Phase 6 that tried to add it
later would find every existing account unrecoverable — which would make Phase 6 depend on work
that Phase 1 had to have done, violating the spec's own phase rule.

### D3 — `recoveryKeyCreatedAt` dropped at MVP

**Why:** YAGNI. The recovery key is generated exactly once, at signup, so `user.createdAt` already
records when. Phase 6 reintroduces the column if recovery keys become regenerable.

```ts
const CROCKFORD = "0123456789ABCDEFGHJKMNPQRSTVWXYZ";

export function utf8ToBytes(value: string): Uint8Array {
  return new TextEncoder().encode(value);
}

export function bytesToUtf8(bytes: Uint8Array): string {
  return new TextDecoder().decode(bytes);
}

export function toBase64Url(bytes: Uint8Array): string {
  let binary = "";
  for (const byte of bytes) binary += String.fromCharCode(byte);
  return btoa(binary).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

export function fromBase64Url(value: string): Uint8Array {
  const base64 = value.replace(/-/g, "+").replace(/_/g, "/");
  const padded = base64.length % 4 === 0 ? base64 : base64 + "=".repeat(4 - (base64.length % 4));
  const binary = atob(padded);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i);
  return bytes;
}

export function toCrockfordBase32(bytes: Uint8Array): string {
  let bits = 0;
  let accumulator = 0;
  let out = "";
  for (const byte of bytes) {
    accumulator = (accumulator << 8) | byte;
    bits += 8;
    while (bits >= 5) {
      out += CROCKFORD[(accumulator >>> (bits - 5)) & 31];
      bits -= 5;
    }
  }
  if (bits > 0) out += CROCKFORD[(accumulator << (5 - bits)) & 31];
  return out;
}

export function fromCrockfordBase32(value: string): Uint8Array {
  let bits = 0;
  let accumulator = 0;
  const out: number[] = [];
  for (const char of value.toUpperCase()) {
    const index = CROCKFORD.indexOf(char);
    if (index === -1) throw new Error(`invalid base32 character: ${char}`);
    accumulator = (accumulator << 5) | index;
    bits += 5;
    if (bits >= 8) {
      out.push((accumulator >>> (bits - 8)) & 255);
      bits -= 8;
    }
  }
  return new Uint8Array(out);
}
```

async function emailSalt(normalizedEmail: string): Promise<Uint8Array> {
  const digest = await crypto.subtle.digest(
    "SHA-256",
    utf8ToBytes(`${SALT_DOMAIN}:${normalizedEmail}`),
  );
  return new Uint8Array(digest);
}

export async function deriveMasterKey(
  masterPassword: string,
  email: string,
): Promise<Uint8Array> {
  const normalized = normalizeEmail(email);
  if (normalized.length === 0) throw new Error("email is required for key derivation");

  return argon2id({
    password: utf8ToBytes(masterPassword),
    salt: await emailSalt(normalized),
    iterations: ARGON2_ITERATIONS,
    parallelism: ARGON2_PARALLELISM,
    memorySize: ARGON2_MEMORY_KIB,
    hashLength: ARGON2_HASH_LEN,
    outputType: "binary",
  });
}

/** The value sent to Better Auth in place of a password. */
export async function deriveAuthHash(
  masterKey: Uint8Array,
  masterPassword: string,
): Promise<string> {
  const bytes = await pbkdf2({
    password: masterKey,
    salt: utf8ToBytes(masterPassword),
    iterations: AUTH_HASH_ITERATIONS,
    hashLength: AUTH_HASH_LEN,
    hashFunction: createSHA256(),
    outputType: "binary",
  });
  return toBase64Url(bytes);
}

/** Expands the master key into the AES-GCM key that wraps the vault key. */
export async function stretchMasterKey(masterKey: Uint8Array): Promise<CryptoKey> {
  const material = await crypto.subtle.importKey("raw", masterKey, "HKDF", false, ["deriveKey"]);
  return crypto.subtle.deriveKey(
    {
      name: "HKDF",
      hash: "SHA-256",
      salt: new Uint8Array(0),
      info: utf8ToBytes(HKDF_INFO_VAULT),
    },
    material,
    { name: "AES-GCM", length: AES_KEY_BITS },
    false, // non-extractable: this key must never leave the worker
    ["encrypt", "decrypt"],
  );
}

Two distinct error types matter: a malformed string is a **programming or storage** fault, while a

```ts
import { AES_IV_BYTES, AES_TAG_BITS, CIPHER_VERSION } from "./constants";
import { bytesToUtf8, fromBase64Url, toBase64Url, utf8ToBytes } from "./encoding";

/** The cipher string is not in a shape we recognise. */
export class CipherFormatError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "CipherFormatError";
  }
}

/** The auth tag did not verify: wrong key, or the ciphertext was altered. */
export class DecryptionError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "DecryptionError";
  }
}

export async function encryptBytes(plaintext: Uint8Array, key: CryptoKey): Promise<string> {
  const iv = crypto.getRandomValues(new Uint8Array(AES_IV_BYTES));
  const ciphertext = await crypto.subtle.encrypt(
    { name: "AES-GCM", iv, tagLength: AES_TAG_BITS },
    key,
    plaintext,
  );
  return `${CIPHER_VERSION}.${toBase64Url(iv)}.${toBase64Url(new Uint8Array(ciphertext))}`;
}

export async function decryptBytes(cipher: string, key: CryptoKey): Promise<Uint8Array> {
  const parts = cipher.split(".");
  if (parts.length !== 3) {
    throw new CipherFormatError(`expected 3 parts, received ${parts.length}`);
  }
  const [version, encodedIv, encodedPayload] = parts as [string, string, string];
  if (version !== CIPHER_VERSION) {
    throw new CipherFormatError(`unsupported cipher version: ${version}`);
  }

  let iv: Uint8Array;
  let payload: Uint8Array;
  try {
    iv = fromBase64Url(encodedIv);
    payload = fromBase64Url(encodedPayload);
  } catch {
    throw new CipherFormatError("cipher string is not valid base64url");
  }
  if (iv.length !== AES_IV_BYTES) {
    throw new CipherFormatError(`expected a ${AES_IV_BYTES} byte iv, received ${iv.length}`);
  }

  try {
    const plaintext = await crypto.subtle.decrypt(
      { name: "AES-GCM", iv, tagLength: AES_TAG_BITS },
      key,
      payload,
    );
    return new Uint8Array(plaintext);
  } catch {
    // Deliberately opaque: never reveal which part failed.
    throw new DecryptionError("decryption failed");
  }
}

export async function encryptItem(value: unknown, key: CryptoKey): Promise<string> {
  return encryptBytes(utf8ToBytes(JSON.stringify(value)), key);
}

export async function decryptItem(cipher: string, key: CryptoKey): Promise<unknown> {
  const plaintext = await decryptBytes(cipher, key);
  try {
    return JSON.parse(bytesToUtf8(plaintext));
  } catch {
    throw new DecryptionError("decrypted payload is not valid json");
  }
}

import { decryptBytes, DecryptionError, encryptBytes } from "./cipher";
import { AES_KEY_BITS, VAULT_KEY_BYTES } from "./constants";

/** Generated once per account and never rotated. Items are encrypted with this,
 *  which is why changing the master password does not re-encrypt the vault. */
export async function generateVaultKey(): Promise<CryptoKey> {
  return crypto.subtle.generateKey(
    { name: "AES-GCM", length: AES_KEY_BITS },
    true, // extractable, so it can be exported and wrapped
    ["encrypt", "decrypt"],
  );
}

export async function wrapVaultKey(
  vaultKey: CryptoKey,
  wrappingKey: CryptoKey,
): Promise<string> {
  const raw = new Uint8Array(await crypto.subtle.exportKey("raw", vaultKey));
  return encryptBytes(raw, wrappingKey);
}

export async function unwrapVaultKey(
  wrapped: string,
  wrappingKey: CryptoKey,
): Promise<CryptoKey> {
  const raw = await decryptBytes(wrapped, wrappingKey);
  if (raw.length !== VAULT_KEY_BYTES) {
    throw new DecryptionError("unwrapped vault key has an unexpected length");
  }
  return crypto.subtle.importKey(
    "raw",
    raw,
    { name: "AES-GCM", length: AES_KEY_BITS },
    true,
    ["encrypt", "decrypt"],
  );
}

import {
  AES_KEY_BITS, HKDF_INFO_RECOVERY, HKDF_INFO_RECOVERY_AUTH, RECOVERY_GROUP_SIZE,
  RECOVERY_KEY_BYTES, RECOVERY_PREFIX,
} from "./constants";
import { fromCrockfordBase32, toBase64Url, toCrockfordBase32, utf8ToBytes } from "./encoding";

/** Strips the prefix and any separators a person may have typed or omitted. */
function extractPayload(display: string): string {
  const upper = display.toUpperCase().replace(/[\s-]/g, "");
  const prefix = RECOVERY_PREFIX.replace(/-/g, "");
  return upper.startsWith(prefix) ? upper.slice(prefix.length) : upper;
}

function formatDisplay(payload: string): string {
  const groups = payload.match(new RegExp(`.{1,${RECOVERY_GROUP_SIZE}}`, "g")) ?? [];
  return [RECOVERY_PREFIX, ...groups].join("-");
}

export async function deriveRecoveryWrappingKey(display: string): Promise<CryptoKey> {
  const bytes = fromCrockfordBase32(extractPayload(display));
  if (bytes.length !== RECOVERY_KEY_BYTES) {
    throw new Error("invalid recovery key: unexpected length");
  }
  const material = await crypto.subtle.importKey("raw", bytes, "HKDF", false, ["deriveKey"]);
  return crypto.subtle.deriveKey(
    {
      name: "HKDF",
      hash: "SHA-256",
      salt: new Uint8Array(0),
      // Domain-separated from the vault path so the two derivations can never collide.
      info: utf8ToBytes(HKDF_INFO_RECOVERY),
    },
    material,
    { name: "AES-GCM", length: AES_KEY_BITS },
    false,
    ["encrypt", "decrypt"],
  );
}

/**
 * Derives the value that proves possession of the recovery key to the server.
 *
 * Domain-separated from the wrapping key, so the server never holds anything
 * related to the key that actually unwraps the vault. The server hashes this
 * again before storing it. See deviation D5.
 */
export async function deriveRecoveryAuthHash(display: string): Promise<string> {
  const bytes = fromCrockfordBase32(extractPayload(display));
  if (bytes.length !== RECOVERY_KEY_BYTES) {
    throw new Error("invalid recovery key: unexpected length");
  }
  const material = await crypto.subtle.importKey("raw", bytes, "HKDF", false, ["deriveBits"]);
  const derived = await crypto.subtle.deriveBits(
    {
      name: "HKDF",
      hash: "SHA-256",
      salt: new Uint8Array(0),
      info: utf8ToBytes(HKDF_INFO_RECOVERY_AUTH),
    },
    material,
    256,
  );
  return toBase64Url(new Uint8Array(derived));
}

/** Shown to the user exactly once, at signup. Never stored in plaintext. */
export async function generateRecoveryKey(): Promise<{ display: string; key: CryptoKey }> {
  const bytes = crypto.getRandomValues(new Uint8Array(RECOVERY_KEY_BYTES));
  const display = formatDisplay(toCrockfordBase32(bytes));
  return { display, key: await deriveRecoveryWrappingKey(display) };
}

import { deriveAuthHash, deriveMasterKey, stretchMasterKey } from "../crypto";

export interface DerivationResult {
  authHash: string;
  stretchedKey: CryptoKey;
}

/** The only expensive operation in the app. Runs once per unlock. */
export async function performDerivation(
  masterPassword: string,
  email: string,
): Promise<DerivationResult> {
  const masterKey = await deriveMasterKey(masterPassword, email);
  try {
    return {
      authHash: await deriveAuthHash(masterKey, masterPassword),
      stretchedKey: await stretchMasterKey(masterKey),
    };
  } finally {
    masterKey.fill(0); // do not leave the master key sitting in worker memory
  }
}
```

- [ ] **Step 5: Implement `src/lib/crypto-worker/worker.ts`**

`CryptoKey` is structured-cloneable, so the derived key can cross the worker boundary without ever
being exported to raw bytes.

```ts
import { performDerivation } from "./derive";

export interface DeriveRequest {
  id: string;
  masterPassword: string;
  email: string;
}

export type DeriveResponse =
  | { id: string; ok: true; authHash: string; stretchedKey: CryptoKey }
  | { id: string; ok: false; error: string };

self.addEventListener("message", (event: MessageEvent<DeriveRequest>) => {
  const { id, masterPassword, email } = event.data;
  void performDerivation(masterPassword, email)
    .then(({ authHash, stretchedKey }) => {
      self.postMessage({ id, ok: true, authHash, stretchedKey } satisfies DeriveResponse);
    })
    .catch((error: unknown) => {
      const message = error instanceof Error ? error.message : "derivation failed";
      self.postMessage({ id, ok: false, error: message } satisfies DeriveResponse);
    });
});
```

- [ ] **Step 6: Implement `src/lib/crypto-worker/client.ts`**

A fresh worker per call. Derivation happens at most a few times per session, so pooling would add
state for no benefit — and terminating guarantees nothing lingers in worker memory.

```ts
import type { DeriveRequest, DeriveResponse, DerivationResult } from "./worker";

export function deriveInWorker(
  masterPassword: string,
  email: string,
): Promise<DerivationResult> {
  return new Promise((resolve, reject) => {
    const worker = new Worker(new URL("./worker.ts", import.meta.url));
    const id = crypto.randomUUID();

    const cleanup = () => worker.terminate();

    worker.addEventListener("message", (event: MessageEvent<DeriveResponse>) => {
      if (event.data.id !== id) return;
      cleanup();
      if (event.data.ok) {
        resolve({ authHash: event.data.authHash, stretchedKey: event.data.stretchedKey });
      } else {
        reject(new Error(event.data.error));
      }
    });

    worker.addEventListener("error", (event) => {
      cleanup();
      reject(new Error(event.message || "derivation worker failed"));
    });

    worker.postMessage({ id, masterPassword, email } satisfies DeriveRequest);
  });
}
```

"use client";

import { createContext, useCallback, useContext, useMemo, useState } from "react";

interface VaultContextValue {
  vaultKey: CryptoKey | null;
  isUnlocked: boolean;
  unlock: (key: CryptoKey) => void;
  lock: () => void;
}

const VaultContext = createContext<VaultContextValue | null>(null);

/**
 * Holds the unwrapped vault key in memory for the lifetime of the tab.
 *
 * The key is NEVER written to localStorage, sessionStorage, IndexedDB or a cookie.
 * A reload re-locks the vault by design — that is the feature, not a gap.
 */
export function VaultProvider({ children }: { children: React.ReactNode }) {
  const [vaultKey, setVaultKey] = useState<CryptoKey | null>(null);

  const unlock = useCallback((key: CryptoKey) => setVaultKey(key), []);
  const lock = useCallback(() => setVaultKey(null), []);

  const value = useMemo(
    () => ({ vaultKey, isUnlocked: vaultKey !== null, unlock, lock }),
    [vaultKey, unlock, lock],
  );

  return <VaultContext.Provider value={value}>{children}</VaultContext.Provider>;
}

export function useVault(): VaultContextValue {
  const context = useContext(VaultContext);
  if (!context) throw new Error("useVault must be used inside a VaultProvider");
  return context;
}

```ts
import {
  deriveRecoveryAuthHash, generateRecoveryKey, generateVaultKey, wrapVaultKey,
} from "~/lib/crypto";
import { deriveInWorker } from "~/lib/crypto-worker/client";

export interface SignupPayload {
  email: string;
  password: string; // the auth hash — never the master password
  protectedVaultKey: string;
  recoveryWrappedVaultKey: string;
  recoveryVerifier: string; // proves possession of the recovery key in Phase 6
  recoveryDisplay: string; // shown once, never sent
}

export async function buildSignupPayload(
  email: string,
  masterPassword: string,
): Promise<SignupPayload> {
  const { authHash, stretchedKey } = await deriveInWorker(masterPassword, email);
  const vaultKey = await generateVaultKey();
  const recovery = await generateRecoveryKey();

  return {
    email,
    password: authHash,
    protectedVaultKey: await wrapVaultKey(vaultKey, stretchedKey),
    recoveryWrappedVaultKey: await wrapVaultKey(vaultKey, recovery.key),
    recoveryVerifier: await deriveRecoveryAuthHash(recovery.display),
    recoveryDisplay: recovery.display,
  };

  | { ok: false };

import { TRPCError } from "@trpc/server";
import { and, desc, eq, isNull } from "drizzle-orm";
import { z } from "zod";
import { createTRPCRouter, protectedProcedure } from "~/server/api/trpc";
import { item } from "~/server/db/schema";

/** The server cannot read the contents, but it can insist on the envelope shape
 *  so a malformed blob never reaches storage. */
const ciphertext = z.string().regex(/^v1\.[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+$/, "malformed ciphertext");

export const itemRouter = createTRPCRouter({
  list: protectedProcedure.query(async ({ ctx }) => {
    return ctx.db
      .select({
        id: item.id,
        ciphertext: item.ciphertext,
        createdAt: item.createdAt,
        updatedAt: item.updatedAt,
      })
      .from(item)
      .where(and(eq(item.userId, ctx.session.user.id), isNull(item.deletedAt)))
      .orderBy(desc(item.updatedAt));
  }),

  create: protectedProcedure
    .input(z.object({ ciphertext }))
    .mutation(async ({ ctx, input }) => {
      const [created] = await ctx.db
        .insert(item)
        .values({ userId: ctx.session.user.id, ciphertext: input.ciphertext })
        .returning({ id: item.id });
      return created!;
    }),

  update: protectedProcedure
    .input(z.object({ id: z.string().uuid(), ciphertext }))
    .mutation(async ({ ctx, input }) => {
      // Ownership lives in the WHERE clause. Another user's row is indistinguishable
      // from a row that does not exist.
      const [updated] = await ctx.db
        .update(item)
        .set({ ciphertext: input.ciphertext, updatedAt: new Date() })
        .where(and(eq(item.id, input.id), eq(item.userId, ctx.session.user.id)))
        .returning({ id: item.id });

      if (!updated) throw new TRPCError({ code: "NOT_FOUND" });
      return updated;
    }),

  delete: protectedProcedure
    .input(z.object({ id: z.string().uuid() }))
    .mutation(async ({ ctx, input }) => {
      const [deleted] = await ctx.db
        .update(item)
        .set({ deletedAt: new Date() })
        .where(and(eq(item.id, input.id), eq(item.userId, ctx.session.user.id)))
        .returning({ id: item.id });

      if (!deleted) throw new TRPCError({ code: "NOT_FOUND" });
      return deleted;
    }),

  restore: protectedProcedure
    .input(z.object({ id: z.string().uuid() }))
    .mutation(async ({ ctx, input }) => {
      const [restored] = await ctx.db
        .update(item)
        .set({ deletedAt: null })
        .where(and(eq(item.id, input.id), eq(item.userId, ctx.session.user.id)))
        .returning({ id: item.id });

      if (!restored) throw new TRPCError({ code: "NOT_FOUND" });
      return restored;
    }),
});

import { decryptItem } from "~/lib/crypto";
import { type Item, itemSchema } from "./schema";

export interface EncryptedRow {
  id: string;
  ciphertext: string;
  createdAt: Date;
  updatedAt: Date;
}

export interface DecryptedItem {
  id: string;
  data: Item;
  createdAt: Date;
  updatedAt: Date;
}

export interface DecryptedVault {
  items: DecryptedItem[];
  /** Ids that could not be decrypted or failed validation. Never discarded — the
   *  ciphertext stays in the database and may be recoverable. */
  damaged: string[];
}

export async function decryptVault(
  rows: EncryptedRow[],
  vaultKey: CryptoKey,
): Promise<DecryptedVault> {
  const items: DecryptedItem[] = [];
  const damaged: string[] = [];

  for (const row of rows) {
    try {
      const parsed = itemSchema.safeParse(await decryptItem(row.ciphertext, vaultKey));
      if (!parsed.success) {
        damaged.push(row.id);
        continue;
      }
      items.push({
        id: row.id,
        data: parsed.data,
        createdAt: row.createdAt,
        updatedAt: row.updatedAt,
      });
    } catch {
      damaged.push(row.id);
    }
  }

  return { items, damaged };
}
```

export const CLIPBOARD_CLEAR_MS = 30_000;

let pendingClear: ReturnType<typeof setTimeout> | null = null;

/** Copies a secret and schedules the clipboard to be wiped. Returns false when
 *  the browser refused — for example outside a secure context. */
export async function copyWithAutoClear(value: string): Promise<boolean> {
  if (pendingClear !== null) {
    clearTimeout(pendingClear);
    pendingClear = null;
  }

  try {
    await navigator.clipboard.writeText(value);
  } catch {
    return false;
  }

  pendingClear = setTimeout(() => {
    void navigator.clipboard.writeText("").catch(() => undefined);
    pendingClear = null;
  }, CLIPBOARD_CLEAR_MS);

  return true;
}

```ts
import { Secret, TOTP, URI } from "otpauth";

export interface TotpConfig {
  secret: string; // base32
  digits?: number;
  period?: number;
  algorithm?: string;
}

export const TOTP_DEFAULTS = { digits: 6, period: 30, algorithm: "SHA1" } as const;

function toTotp(config: TotpConfig): TOTP {
  return new TOTP({
    secret: Secret.fromBase32(config.secret),
    digits: config.digits ?? TOTP_DEFAULTS.digits,
    period: config.period ?? TOTP_DEFAULTS.period,
    algorithm: config.algorithm ?? TOTP_DEFAULTS.algorithm,
  });
}

/** Generated entirely client-side against the browser clock. No server involved. */
export function generateTotp(config: TotpConfig, timestampMs: number = Date.now()): string {
  return toTotp(config).generate({ timestamp: timestampMs });
}

export function secondsRemaining(period: number, timestampMs: number = Date.now()): number {
  const elapsed = Math.floor(timestampMs / 1000) % period;
  return period - elapsed;
}

/** Accepts an otpauth:// URI or a raw base32 secret, however the user pasted it. */
export function parseTotpInput(input: string): TotpConfig | null {
  const trimmed = input.trim();
  if (trimmed.length === 0) return null;

  if (trimmed.toLowerCase().startsWith("otpauth://")) {
    try {
      const parsed = URI.parse(trimmed);
      if (!(parsed instanceof TOTP)) return null;

      const config: TotpConfig = { secret: parsed.secret.base32 };
      if (parsed.digits !== TOTP_DEFAULTS.digits) config.digits = parsed.digits;
      if (parsed.period !== TOTP_DEFAULTS.period) config.period = parsed.period;
      if (parsed.algorithm !== TOTP_DEFAULTS.algorithm) config.algorithm = parsed.algorithm;
      return config;
    } catch {
      return null;
    }
  }

  const normalized = trimmed.replace(/[\s-]/g, "").toUpperCase();
  try {
    Secret.fromBase32(normalized); // throws when the alphabet is wrong
    return { secret: normalized };
  } catch {
    return null;
  }
}
```

import { wordlist } from "@scure/bip39/wordlists/english";

export interface GeneratorOptions {
  length: number;
  lowercase: boolean;
  uppercase: boolean;
  digits: boolean;
  symbols: boolean;
  excludeAmbiguous: boolean;
}

export const DEFAULT_GENERATOR_OPTIONS: GeneratorOptions = {
  length: 20,
  lowercase: true,
  uppercase: true,
  digits: true,
  symbols: true,
  excludeAmbiguous: false,
};

const CLASSES = {
  lowercase: "abcdefghijklmnopqrstuvwxyz",
  uppercase: "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
  digits: "0123456789",
  symbols: "!@#$%^&*()-_=+[]{};:,.?",
} as const;

const AMBIGUOUS = /[Il1O0]/g;

/** Rejection sampling. `value % bound` alone biases toward low indices. */
function randomIndex(bound: number): number {
  if (bound <= 0) throw new Error("bound must be positive");
  const limit = Math.floor(0xffff_ffff / bound) * bound;
  const buffer = new Uint32Array(1);
  let value: number;
  do {
    crypto.getRandomValues(buffer);
    value = buffer[0]!;
  } while (value >= limit);
  return value % bound;
}

function pick(alphabet: string): string {
  return alphabet[randomIndex(alphabet.length)]!;
}

/** Fisher-Yates, so the guaranteed one-per-class characters do not sit in a fixed order. */
function shuffle(characters: string[]): string[] {
  for (let i = characters.length - 1; i > 0; i--) {
    const j = randomIndex(i + 1);
    [characters[i], characters[j]] = [characters[j]!, characters[i]!];
  }
  return characters;
}

export function generatePassword(options: GeneratorOptions): string {
  const enabled = (["lowercase", "uppercase", "digits", "symbols"] as const)
    .filter((name) => options[name])
    .map((name) =>
      options.excludeAmbiguous ? CLASSES[name].replace(AMBIGUOUS, "") : CLASSES[name],
    )
    .filter((alphabet) => alphabet.length > 0);

  if (enabled.length === 0) throw new Error("at least one character class must be enabled");
  if (options.length < enabled.length) {
    throw new Error("length must be at least the number of enabled character classes");
  }

  // One from each class first, so every enabled class is genuinely represented.
  const characters = enabled.map(pick);
  const combined = enabled.join("");
  while (characters.length < options.length) characters.push(pick(combined));

  return shuffle(characters).join("");
}

export function generatePassphrase(wordCount: number, separator: string): string {
  if (wordCount < 3) throw new Error("a passphrase needs at least 3 words");
  return Array.from({ length: wordCount }, () => wordlist[randomIndex(wordlist.length)]!)
    .join(separator);
}

import type { DecryptedItem } from "./decrypt-vault";

/**
 * Searches only the fields a person would search by.
 *
 * Passwords, TOTP secrets and notes are deliberately excluded: matching on a
 * password would let anyone at the keyboard confirm a guess by typing it in.
 */
function haystack(item: DecryptedItem): string {
  const data = item.data as Record<string, unknown>;
  return [data.title, data.username, data.uri]
    .filter((value): value is string => typeof value === "string")
    .join(" ")
    .toLowerCase();
}

export function searchItems(items: DecryptedItem[], query: string): DecryptedItem[] {
  const needle = query.trim().toLowerCase();
  if (needle.length === 0) return items;
  return items.filter((item) => haystack(item).includes(needle));
}

```ts
"use client";

import { useEffect, useRef } from "react";

const ACTIVITY_EVENTS = ["keydown", "pointerdown", "pointermove", "scroll", "focus"] as const;

export interface AutoLockOptions {
  timeoutMs: number;
  isUnlocked: boolean;
  onLock: () => void;
}

export function useAutoLock({ timeoutMs, isUnlocked, onLock }: AutoLockOptions): void {
  const onLockRef = useRef(onLock);
  onLockRef.current = onLock;

  useEffect(() => {
    if (!isUnlocked) return;

    let timer: ReturnType<typeof setTimeout>;

    const reset = () => {
      clearTimeout(timer);
      timer = setTimeout(() => onLockRef.current(), timeoutMs);
    };

    reset();
    for (const event of ACTIVITY_EVENTS) {
      window.addEventListener(event, reset, { passive: true });
    }

    return () => {
      clearTimeout(timer);
      for (const event of ACTIVITY_EVENTS) window.removeEventListener(event, reset);
    };
  }, [timeoutMs, isUnlocked]);
}
```

function digitsOnly(value: string): string {
  return value.replace(/\D/g, "");
}

export function formatCardNumber(value: string): string {
  const digits = digitsOnly(value);
  if (digits.length === 15) {
    // Amex groups 4-6-5.
    return [digits.slice(0, 4), digits.slice(4, 10), digits.slice(10)]
      .filter(Boolean)
      .join(" ");
  }
  return digits.match(/.{1,4}/g)?.join(" ") ?? "";
}

export function maskCardNumber(value: string): string {
  const digits = digitsOnly(value);
  if (digits.length === 0) return "";
  if (digits.length <= 4) return "•".repeat(digits.length);

  const masked = "•".repeat(digits.length - 4) + digits.slice(-4);
  if (digits.length === 15) {
    return [masked.slice(0, 3), masked.slice(3, 9), masked.slice(9)].join(" ");
  }
  return masked.match(/.{1,4}/g)?.join(" ") ?? masked;
}

# Phase 6 — Recovery

**Ships:** using the recovery key printed in Phase 1, set a new master password and confirm every
existing item still decrypts — proving the vault key survived unchanged.
**Smoke routes:** everything from Phase 5, plus `/recover` and `/settings/security`

---

## The problem this phase solves

The recovery key cannot authenticate to the server on its own. The server holds only
`recoveryWrappedVaultKey`, which is ciphertext — it has no way to tell a correct recovery key from
a wrong one, so it cannot authorise a password change.

So a **verifier** is needed: a value derived from the recovery key, stored server-side under Better
Auth's own password hasher. Presenting it proves possession of the recovery key without ever
revealing it.

Crucially, the verifier must be created **at signup** (Phase 1), because the recovery key is shown
exactly once and can never be reconstructed afterwards. That is why Tasks 1.8, 1.9, 1.11, 1.12 and
1.16 already include it — see deviation **D5**. This phase consumes what Phase 1 created.

The recovery key carries 240 bits of entropy, so guessing it is infeasible. The lockout below
exists to stop an attacker generating load, not because brute force is a credible threat.

import { TRPCError } from "@trpc/server";
import { and, eq } from "drizzle-orm";
import { z } from "zod";
import { normalizeEmail } from "~/lib/crypto";
import { createTRPCRouter, publicProcedure } from "~/server/api/trpc";
import { auth } from "~/server/better-auth/config";
import { account, session, user } from "~/server/db/schema";

const MAX_ATTEMPTS = 5;
const LOCKOUT_MS = 15 * 60 * 1000;

const ciphertext = z.string().regex(/^v1\.[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+$/);

export const recoveryRouter = createTRPCRouter({
  /**
   * Redeems a recovery key: proves possession via the stored verifier, then
   * rotates the master password, both wrapped copies of the vault key, and the
   * recovery key itself.
   *
   * The vault key inside those wrappings is unchanged, which is why no item has
   * to be re-encrypted.
   */
  recover: publicProcedure
    .input(
      z.object({
        email: z.string().email(),
        recoveryAuthHash: z.string().min(1),
        newAuthHash: z.string().min(8).max(128),
        newProtectedVaultKey: ciphertext,
        newRecoveryWrappedVaultKey: ciphertext,
        newRecoveryVerifier: z.string().min(1),
      }),
    )
    .mutation(async ({ ctx, input }) => {
      const context = await auth.$context;
      const email = normalizeEmail(input.email);

      const [existing] = await ctx.db
        .select()
        .from(user)
        .where(eq(user.email, email))
        .limit(1);

      // Identical error for an unknown account and a wrong key: no enumeration.
      const unauthorized = new TRPCError({
        code: "UNAUTHORIZED",
        message: "recovery failed",
      });
      if (!existing) throw unauthorized;

      if (existing.recoveryLockedUntil && existing.recoveryLockedUntil > new Date()) {
        throw new TRPCError({
          code: "TOO_MANY_REQUESTS",
          message: "too many recovery attempts",
        });
      }

      const valid = await context.password.verify({
        hash: existing.recoveryVerifier,
        password: input.recoveryAuthHash,
      });

      if (!valid) {
        const attempts = existing.recoveryFailedAttempts + 1;
        await ctx.db
          .update(user)
          .set({
            recoveryFailedAttempts: attempts,
            recoveryLockedUntil:
              attempts >= MAX_ATTEMPTS ? new Date(Date.now() + LOCKOUT_MS) : null,
          })
          .where(eq(user.id, existing.id));
        throw unauthorized;
      }

      const [hashedAuth, hashedVerifier] = await Promise.all([
        context.password.hash(input.newAuthHash),
        context.password.hash(input.newRecoveryVerifier),
      ]);

      await ctx.db
        .update(user)
        .set({
          protectedVaultKey: input.newProtectedVaultKey,

        .set({ password: hashedAuth })

```ts
import {
  deriveRecoveryAuthHash, deriveRecoveryWrappingKey,
  generateRecoveryKey, unwrapVaultKey, wrapVaultKey,
} from "~/lib/crypto";
import { deriveInWorker } from "~/lib/crypto-worker/client";

export interface RecoveryInput {
  email: string;
  recoveryDisplay: string;
  recoveryWrappedVaultKey: string;
  newMasterPassword: string;
}

export interface RecoveryPayload {
  email: string;
  recoveryAuthHash: string;
  newAuthHash: string;
  newProtectedVaultKey: string;
  newRecoveryWrappedVaultKey: string;
  newRecoveryVerifier: string;
  /** Shown to the user, never sent. Stripped before the mutation call. */
  newRecoveryDisplay: string;
}

export async function buildRecoveryPayload(input: RecoveryInput): Promise<RecoveryPayload> {
  // Unwrapping here is the proof that the typed recovery key is correct.
  // It throws before anything reaches the network if it is not.
  const oldWrappingKey = await deriveRecoveryWrappingKey(input.recoveryDisplay);
  const vaultKey = await unwrapVaultKey(input.recoveryWrappedVaultKey, oldWrappingKey);

  const { authHash, stretchedKey } = await deriveInWorker(input.newMasterPassword, input.email);
  const nextRecovery = await generateRecoveryKey();

  return {
    email: input.email,
    recoveryAuthHash: await deriveRecoveryAuthHash(input.recoveryDisplay),
    newAuthHash: authHash,
    // The SAME vault key, re-wrapped. This is why no item is re-encrypted.
    newProtectedVaultKey: await wrapVaultKey(vaultKey, stretchedKey),
    newRecoveryWrappedVaultKey: await wrapVaultKey(vaultKey, nextRecovery.key),
    newRecoveryVerifier: await deriveRecoveryAuthHash(nextRecovery.display),
    newRecoveryDisplay: nextRecovery.display,
  };
}
```
