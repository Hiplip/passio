passio autofill test page

Each section is a form passio should treat differently. The green line says what passing looks like. Nothing here submits anywhere — every form has onsubmit="return false".

1 · Ordinary login

Baseline: fill should populate both fields.

2 · Hidden password trap (A2)

There is an off-screen password field above the visible one. Only the visible field may be filled. Check the hidden one with document.getElementById('trap-pw').value — it must stay empty.

3 · Hidden username trap (A2)

An off-screen text field marked autocomplete="username". It must stay empty: check document.getElementById('trap-user').value.

4 · Change password (A3)

Two password fields. passio must refuse — "No login form on this page" — and type nothing at all.

5 · Two-step login

Email only, no password field yet — as Google and Microsoft do. Fill should populate the email and leave it at that.

6 · Search box, not a login

An unmarked text field. It must get no passio button — otherwise every search box on the web would sprout one.

7 · Disabled and read-only

Neither may be filled or decorated.
